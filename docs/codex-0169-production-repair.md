# Codex 0.169 production protocol repair

Baseline: `472026a0da9bc6ffac3b4e9000cd93be61ace22f` (PR #14), verified against origin/main,
release checkout and the previous production image `6053c2b2d8a5`.
The old dirty `999b083` service checkout is used only for live Compose/configuration.
Its November 13 image `8a51675809c8` must not be used as an application source baseline.

## Protocol audit

Reference: official `rust-v0.169.0` (`d32063f96c2dff1dc96af839b3952abb6acfeda4`), plus
experimental JSON schemas generated by the running 0.169.0 executable. Comparison artifacts:
`/xs-train-nas/workspace_wjg/envs/codex-gateway-validation-artifacts/protocol-0169-production`.

| Surface | Audit / adaptation |
| --- | --- |
| initialize, opt-out notifications | Keep existing readState opt-out and fallback handling; initialization envelope unchanged. |
| Thread list/read/start/resume/fork | Add nullable attachedToThreadId, separate from parent/fork lineage; keep strict validation. |
| Turn and errors | Preserve PR #14 rootTurnId and error details; route by turn.id. |
| Item completion and history | Existing extensible item/notification handling preserves moderation; contentTokenCount is optional telemetry. Timeline format unchanged. |
| Settings | New environments metadata is accepted by existing extensible settings parser; provider constraints unchanged. |
| Thread items deferred output | Not used: Gateway reads thread/timeline/list and does not request deferOutput. |
| model/list provider filter | Optional new parameter; existing grouped provider/model routing remains authoritative. |
| Other new provider/security/OAuth APIs | Not called by this Gateway; no new product flow introduced. |
| Success response decode failure | Explicit protocol error; turn start/steer classified delivery-uncertain, never automatic resend; browser reconciles native state rather than inventing completion. Queue retains its existing pause-on-uncertain behavior. |
| Runtime version | Inspect running daemon version; don't restart a supported active runtime for a stale separate CLI. Newer versions are explicitly unverified, not called latest/compatible. |
